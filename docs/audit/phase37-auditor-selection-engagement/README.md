## Purpose of Phase 37

The Phase 36 kickoff package (`docs/audit/phase36-independent-audit-kickoff/`) made the codebase
**auditor-ready**. Phase 37 makes the owner **selection-ready**: criteria, scoring, conflict-of-interest
checks, due-diligence questions, scope options, NDA guidance, budget/timeline templates, a shortlist
placeholder, a decision log, outreach drafts, a readiness checklist, red flags, and communication rules.

## What is prepared (this package)

- `AUDITOR_SELECTION_CRITERIA.md` — weighted criteria for evaluating candidates.
- `CANDIDATE_SCORECARD_TEMPLATE.md` — reusable scoring table (placeholders only).
- `CONFLICT_OF_INTEREST_CHECKLIST.md` — independence checks.
- `DUE_DILIGENCE_QUESTIONS.md` — questions to ask candidates.
- `ENGAGEMENT_SCOPE_OPTIONS.md` — scope levels A–D.
- `NDA_DECISION_GUIDE.md` — NDA options + recommended default (owner decision).
- `BUDGET_TIMELINE_TEMPLATE.md` — cost/milestone template (no invented numbers).
- `AUDITOR_SHORTLIST_PLACEHOLDER.md` — empty shortlist (no real candidates).
- `OWNER_DECISION_LOG.md` — decision log with initial pending entries.
- `OUTREACH_MESSAGE_VARIANTS.md` — draft messages (NOT sent; placeholders).
- `ENGAGEMENT_READINESS_CHECKLIST.md` — pre-contact checklist.
- `AUDITOR_RED_FLAGS.md` — disqualifying signals.
- `COMMUNICATION_RULES.md` — what may/may not be shared.

## What is NOT done

- No real auditor names, companies, emails, prices, or timelines are invented anywhere in this package
  (all are placeholders for the owner to fill).
- No auditor contacted, no outreach sent, no NDA decided, no budget approved, no audit started.
- No mainnet/public-testnet materials; no source-code changes.
