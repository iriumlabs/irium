⛏️ Irium Mining Guide

Quick Start

  1. Clone the repository: git clone https://github.com/iriumlabs/irium.git
  2. Install dependencies: pip3 install requests cryptography
  3. Create a wallet: python3 scripts/irium-wallet-proper.py
  4. Start mining: python3 scripts/irium-miner.py

Multi-Core Mining

Use the multicore miner for better performance:

./scripts/irium-miner-multicore.sh 4

Replace 4 with your number of CPU cores.

Block Rewards

  • Block Reward: 50 IRM
  • Block Time: ~10 minutes (600 seconds)
  • Maturity: 100 blocks (~16.7 hours)
