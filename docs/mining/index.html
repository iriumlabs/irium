Mining Guide

Mine Irium with your own node or connect to the public Stratum pool. This page is structured for fast setup and production-safe defaults.

Quick Paths

Local CPU Mining

Run iriumd and irium-miner on the same machine for direct local mining.

Public Pool Mining

Use the pool endpoint stratum+tcp://pool.iriumlabs.org:3333 with your wallet address.

ASIC / External Miner

Point your ASIC software to the Stratum pool and monitor blocks from Explorer + Pool Portal.

1. Start Node

  • Run with node config so trusted bootstrap peers are loaded.
  • Open P2P port 38291/tcp for inbound/outbound connectivity.
IRIUM_NODE_CONFIG=configs/node.json ./target/release/iriumd

2. Create Mining Address

./target/release/irium-wallet init
./target/release/irium-wallet list-addresses

Use your own IRM address as miner destination. Keep wallet backups secured offline.

3. Mine Locally

export IRIUM_MINER_ADDRESS=YOUR_IRM_ADDRESS
./target/release/irium-miner

If the miner waits, the node is syncing or RPC endpoint/token is wrong. Validate /status first.

4. Public Pool Connection

  • URL: stratum+tcp://pool.iriumlabs.org:3333
  • Username: IRM_ADDRESS.worker1
  • Password: x

Pool is solo mode: when a valid block is found, reward pays to the address in your username.

Troubleshooting

Height stuck at 0

Node is not synced or RPC unreachable. Check http://127.0.0.1:38300/status and peer count.

InvalidContentType / template errors

Protocol mismatch. Ensure miner RPC URL scheme (HTTP/HTTPS) matches node RPC listener.

401 / 429 errors

Token mismatch or rate limit. Use same IRIUM_RPC_TOKEN on node and miner.

Orphan / unknown parent logs

Usually during sync/forks. Keep node online and let header-first sync catch up.
