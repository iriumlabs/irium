# Pilot FAQ

## Is this mainnet?
No. This pilot is BTC testnet <-> IRM pilot flow only.

## Is Irium mainnet HTLC enabled?
No. HTLCv1 remains disabled by default on Irium mainnet.

## Can I use real funds?
No. Use test/trial funds only.

## What if a swap gets stuck?
Use refund path as instructed and report with `swap_id`, txids, and timestamps.

## Can coordinator access my funds?
No. Coordinator does not custody funds or private keys.

## Who can join?
Selected testers only during approved pilot windows.

## Can I share pilot endpoints publicly?
No, unless operator explicitly authorizes publication.
