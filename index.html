WHAT IS IRIUM?

Irium is a revolutionary proof-of-work blockchain engineered for maximum independence and survivability. Unlike traditional blockchains that rely on DNS infrastructure and centralized services, Irium operates with zero external dependencies.

Launched on October 16, 2025 with a fully mined genesis block after 5.4 billion hashes.

8 CORE INNOVATIONS

🌐

Zero-DNS Bootstrap

No DNS dependencies. Network bootstraps from signed IP lists and checkpoints.

🔄

Self-Healing Peers

Network automatically discovers and promotes reliable nodes with uptime proofs.

🔒

Genesis Vesting

3.5M IRM locked with on-chain timelocks. Transparent and irreversible.

⚡

Relay Rewards

Transaction relays earn 10% of fees without supply inflation.

🛡️

Sybil-Resistant

PoW handshake prevents botnet attacks.

⚓

Anchor Checkpoints

Signed chain anchors protect against eclipse attacks.

📱

Light Client Ready

SPV + NiPoPoW support for mobile wallets.

📝

On-Chain Metadata

Timestamp any document on the blockchain.
