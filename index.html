Uptime proofs and reputation scoring create robust network topology.

3

Genesis Vesting with CLTV

3.5M IRM locked with on-chain time-locks. Transparent and consensus-enforced.

4

Relay Rewards

5

Sybil-resistant Handshake

Anchor-File Consensus

Metadata Commitments

HOW TO RUN IRIUM

Get started in 3 simple steps

1

DOWNLOAD

Download the bootstrap package (includes node, miner, wallet)

wget https://github.com/iriumlabs/irium/releases/download/v1.0.1/irium-bootstrap-v1.0.1.tar.gz
2

INSTALL

Extract and run the installation script

tar -xzf irium-bootstrap-v1.0.1.tar.gz
cd irium-bootstrap-v1.0.1
./install.sh
3

RUN NODE

Start your Irium node and sync with mainnet

python3 scripts/irium-node.py

Additional Commands

Create Wallet

python3 scripts/irium-wallet-proper.py new

Start Mining

python3 scripts/irium-miner.py

Check Balance

python3 scripts/irium-wallet-proper.py balance
