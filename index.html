About Irium

Production-ready blockchain combining SHA-256d PoW security with cutting-edge innovations

🔒

Battle-Tested Security

Built on SHA-256d Proof-of-Work, the same algorithm securing Bitcoin. Every block requires computational proof.

  • SHA-256d double hashing
  • UTXO transaction model
  • Auto difficulty adjustment
  • 100-block maturity
⚡

Innovation-Driven

8 unique protocol-level innovations solving real blockchain challenges.

  • Zero-DNS bootstrap
  • Self-healing peers
  • On-chain vesting
  • Relay rewards
🌍

Truly Decentralized

No central points of failure. Censorship-resistant and community-driven.

  • No DNS dependencies
  • Peer reputation
  • Open source code
  • Transparent governance

8 Unique Innovations

Protocol-level features that set Irium apart

1
🛡️

Zero-DNS Bootstrap

Censorship-resistant network discovery with signed seedlists and anchor files. No reliance on centralized DNS infrastructure.

Signed Seedlists Anchor Files No DNS
2
🔄

Self-healing Peer Discovery

HMAC-based uptime proofs and peer reputation scoring create a robust, self-organizing network topology.

HMAC Proofs Reputation Auto-healing
3
🔐

Genesis Vesting with CLTV

3.5M IRM founder allocation with on-chain OP_CHECKLOCKTIMEVERIFY. Transparent, consensus-enforced, irreversible vesting.

On-chain CLTV 3-Year Vesting 3.5M IRM
4
💸

Per-Transaction Relay Rewards

Nodes earn 10% of transaction fees for relaying. Improves propagation speed and incentivizes node participation.

10% Fee Share Node Incentive Fast Relay
5
🛡️

Sybil-resistant Handshake

PoW-based handshake challenges prevent spam and Sybil attacks. Each connection requires computational proof.

PoW Challenge Spam Protection Ephemeral Keys
6
⚓

Anchor-File Consensus

Rolling header checkpoints protect against eclipse attacks. New nodes verify against community-signed anchors.

Checkpoints Eclipse Protection Signed Anchors

📱

Light Client Support

SPV and NiPoPoW proofs enable mobile wallets. Full security without downloading entire blockchain.

SPV NiPoPoW Mobile Ready
8
📝

On-chain Metadata

Verifiable data commitments in transactions. Enables timestamping, provably fair games, and decentralized apps.

Data Anchoring Timestamps Provably Fair
