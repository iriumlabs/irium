WHAT IS IRIUM?

Irium is a revolutionary proof-of-work blockchain engineered for maximum independence and survivability. Unlike traditional blockchains that rely on DNS infrastructure and centralized services, Irium operates with zero external dependencies.

Launched on October 16, 2025 with a fully mined genesis block after 5.4 billion hashes, Irium is designed to outlast any infrastructure collapse and maintain network consensus even in the most hostile environments.

8 CORE INNOVATIONS

Revolutionary features built into the protocol

🌐

Zero-DNS Bootstrap

No DNS dependencies. Network bootstraps from signed IP lists and checkpoints. Works anywhere, forever.

🔄

Self-Healing Peers

Network automatically discovers and promotes reliable nodes. Uptime proofs ensure only quality peers survive.

🔒

Genesis Vesting (CLTV)

3.5M IRM locked with on-chain timelocks. Transparent, consensus-enforced, irreversible. No trust needed.

⚡

Relay Rewards

Transaction relays earn 10% of fees. Incentivizes fast propagation without supply inflation.

🛡️

Sybil-Resistant P2P

Proof-of-work handshake prevents botnet attacks. Only legitimate nodes can connect.

⚓

Anchor Checkpoints

Signed chain anchors protect against eclipse attacks. New nodes verify against trusted checkpoints.

📱

Light Client Ready

SPV + NiPoPoW support from genesis. Mobile wallets with header-only sync and logarithmic proofs.

📝

On-Chain Metadata

Timestamp any document on the blockchain. Immutable proof of existence for any data.

GET STARTED

Download and run Irium in minutes

Irium Bootstrap Package v1.1.9

Includes node, miner, wallet, and all dependencies

DOWNLOAD v1.1.9 193 KB • Verified ✓
1

Download

wget https://github.com/iriumlabs/irium/releases/download/v1.1.9/irium-bootstrap-v1.1.9.tar.gz
2

Install Dependencies

tar -xzf irium-bootstrap-v1.1.9.tar.gz
cd irium-bootstrap-v1.1.9
pip3 install --user pycryptodome qrcode pillow

⚠️ Required: pycryptodome is needed for wallet creation

3

Run Node

python3 scripts/irium-node.py

Create Wallet

python3 scripts/irium-wallet-proper.py new-address

Start Mining

python3 scripts/irium-miner.py

Check Balance

python3 scripts/irium-wallet-proper.py balance
