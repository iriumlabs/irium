Troubleshooting

Common issues and how to fix them.

  • Port 3333 blocked by ISPUse port 443 — same Stratum, plain TCP via sslh. Disable TLS in miner config.
  • Port 443 also blockedUse port 80 — second fallback.
  • Shares rejected (stale)Check your internet latency to pool.irium.org. Use ping pool.irium.org.
  • Firmware auto-enables TLS on port 443Find the SSL/TLS toggle in your miner UI and disable it explicitly.
  • Reward not receivedCoinbase outputs mature after 100 blocks (~3 h). Check the lookup tool above.
