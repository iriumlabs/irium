FAQ

Node shows height 0 / peers 0

Start with config so seed peers load: IRIUM_NODE_CONFIG=configs/node.json ./target/release/iriumd. Open TCP 38291 in/out.

Bans or disconnects

Check clock and clear peer reputation: timedatectl status and rm -f ~/.irium/peer_reputation.json.

Miner starts at 0/1 and stalls

Miner requires a synced node RPC. Start iriumd first and set IRIUM_MINER_ADDRESS.

InvalidContentType template error

RPC protocol mismatch. Ensure IRIUM_NODE_RPC scheme matches node listener (HTTP vs HTTPS).

RPC token errors

Use same IRIUM_RPC_TOKEN for node + miner/wallet. 401 = mismatch, 429 = rate limit.

Orphan blocks / unknown parent

Often normal during sync or competing tips. Keep node running to fetch missing parents.

Anchors verification failed

Use official release and confirm bootstrap/anchors.json signer files are unchanged.

Can I run miner only?

Miner needs node RPC. Run local node or trusted remote and set IRIUM_NODE_RPC.
