FAQ

Quick answers to common setup questions

🔌

Node shows height 0 / peers = 0

Start with the config so seed peers load:

IRIUM_NODE_CONFIG=configs/node.json ./target/release/iriumd

Open TCP 38291 inbound and outbound.

🛡️

Getting banned or frequent disconnects

Check your clock and clear peer reputation, then restart:

timedatectl status
rm -f ~/.irium/peer_reputation.json

⛏️

Miner starts at height 0/1 and does not move

The miner needs a synced node RPC. Start iriumd first and set IRIUM_MINER_ADDRESS.

🌐

Miner template error: InvalidContentType

This is an RPC protocol mismatch. If node RPC is HTTP, set IRIUM_NODE_RPC=http://127.0.0.1:38300. If node RPC is HTTPS, keep https://127.0.0.1:38300.

Verify both: curl -s http://127.0.0.1:38300/status and curl -sk https://127.0.0.1:38300/status, then restart miner.

🔐

IRIUM_RPC_TOKEN and RPC errors

Use the same token for node + miner or wallet. 401 = bad token, 429 = rate limit.

🧩

Unknown parent / orphan blocks

Normal during sync or competing tips. Keep the node running to fill missing parents.

⚓

Anchors verification failed

Use the official release. Ensure bootstrap/anchors.json and signer files are unchanged.

🧠

Can I run only the miner?

The miner needs a node RPC. Run a local node or set IRIUM_NODE_RPC to a trusted remote node.
